# Гайд — Клешня 2.0: полная сборка и проверка

Это новая версия проекта. Всё лежит в папке `CrabRobot/`.

```text
CrabRobot/
  config.h        ← все настройки: пины, сеть, скорости. ПРАВИТЬ ТОЛЬКО ТУТ
  hardware.h      ← общие объявления (не править)
  CrabRobot.ino   ← основная прошивка: экраны, эмоции, зуммер, сеть, пульт
  movement.ino    ← ходьба: два DC-мотора. ОТДЕЛЬНЫЙ ФАЙЛ
  microphone.ino  ← запись речи с микрофона робота
  brain_v2.py     ← сервер разговора на ноутбуке
  «Гайд — Клешня 2.0.md»  ← этот файл
```

Старые файлы (`crab.ino`, `brain.py`, `Test/Test.ino`) оставлены как есть — их
можно не трогать. Рабочая версия — новая.

---

## Что починено по сравнению со старой версией

| Проблема | Причина | Как исправлено |
|---|---|---|
| Зависала в состоянии «думаю», текст не менялся | ESP32 слал ответы на `/api/reply` и `/api/emotion`, а в старой `crab.ino` таких адресов **не было вообще** (там `/say` и `/emo`). Ответ не доходил никогда | Новые адреса есть в прошивке, и добавлен **сторожевой таймер**: если ответа нет 12 секунд, Клешня сама возвращается в нейтраль и пишет «Нет ответа. Повтори.» |
| Зуммер непрерывно пищал | `digitalWrite(HIGH)` на пассивном зуммере = ровное гудение. Плюс `beep(25)` на каждую команду в танце | Писк только короткими чирпами (меандр вручную). Звук эмоций **выключен** по умолчанию (`EMOTION_SOUND = false`). Есть кнопка «Проверить зуммер» |
| Микрофон не распознавал речь | MAX9814 только мерял громкость | Теперь пишется WAV 8 кГц, отправляется на ноутбук, там faster-whisper распознаёт и отвечает |
| IP ноутбука надо было угадывать вручную | — | ESP32 сам находит ноутбук по UDP (порт 7777) |
| Ходьба была в том же файле | — | Вынесена в `movement.ino` и **выключена** по умолчанию |

## Этап 0. Что нужно

- ESP32 DevKit
- Два OLED: широкий 128×32 (рот) и квадратный 128×64 (глаз)
- AS5600 (энкодер угла) — если есть
- MAX9814 (микрофон)
- Зуммер **пассивный**, с выводом `IN`
- 4 сервопривода MG995 (клешни)
- Двухканальный H-мост (драйвер моторов)
- Два DC-мотора с редуктором (только `+` и `−`)
- Компьютер с интернетом

Библиотеки Arduino IDE: `ESP32Servo`, `U8g2`.

## Этап 1. Подключение (без моторов)

Сначала проверь всё, **не подключая моторы**. Моторы — этап 5.

```text
РОТ (широкий OLED 128×32):
  VCC  → 3V3
  GND  → GND
  SDA  → GPIO21
  SCK  → GPIO22

ГЛАЗ (квадратный OLED 128×64):
  VCC  → 3V3
  GND  → GND
  SDA  → GPIO4
  SCL  → GPIO5

AS5600:
  VCC  → 3V3
  GND  → GND
  SDA  → GPIO21
  SCL  → GPIO22

MAX9814 (микрофон):
  VDD/+ → 3V3
  GND/- → GND
  OUT   → GPIO34

ЗУММЕР (пассивный):
  VCC  → 3V3
  GND  → GND
  IN   → GPIO19

СЕРВОПРИВОДЫ:
  Л. рука   → GPIO13
  Л. клешня → GPIO25
  П. рука   → GPIO27
  П. клешня → GPIO26
  сигнальный провод (жёлтый/оранжевый/белый) — к пину
  красный   → внешнее питание 5–6 В
  чёрный    → общий GND
```

**Обязательно:** общий GND у ESP32, сервоприводов и драйвера моторов.

**GPIO34** — только вход. Ничего к нему не подключай, кроме выхода микрофона.

## Этап 2. Прошивка

1. Открой Arduino IDE.
2. **File → Open…** → выбери папку `CrabRobot` (именно папку, не файл).
3. Плата: **ESP32 Dev Module**.
4. Library Manager → установи `ESP32Servo` и `U8g2`.
5. **Загрузить**.

В Serial Monitor (115200) должно быть:

```text
Клешня Клешня, прошивка 2.0
Рот (128x32): найден
Глаз (128x64): найден
Пульт: http://192.168.4.1
Ходьба: выключена
```

Если написано «НЕ НАЙДЕН» — проверь SDA/SCL и питание экрана.

## Этап 3. Пульт без сети

ESP32 поднимает свою точку доступа `CRAB-ROBOT` (пароль `crab12345`).

1. Телефон → Wi-Fi → `CRAB-ROBOT`.
2. Браузер → `http://192.168.4.1`.

Проверь:

- кнопки эмоций — глаз меняется;
- **«Проверить зуммер»** — короткий чирп, **не непрерывное гудение**;
- поле «Спросить» — покажет, что пульт живой.

## Этап 4. Сеть ноутбука (для нейросети и микрофона)

Три устройства — ESP32, телефон и ноутбук — должны быть **в одной сети**, где разрешено общение между устройствами.

Вариант А (проще): все в одной домашней сети роутера.

1. Узнай IP ноутбука:

```bash
ipconfig getifaddr en0
```

2. Открой `config.h` и впиши:

```cpp
constexpr char STA_SSID[] = "имя_твоей_сети";
constexpr char STA_PASS[] = "пароль_сети";
```

3. Перепрошей ESP32.

Вариант Б: телефон и ноутбук в одной сети, ESP32 — в своей точке `CRAB-ROBOT` (не подходит: тогда ESP32 не увидит ноутбук).

> Если используешь Windows «Мобильный хотспот», IP ноутбука обычно `192.168.137.1`.

## Этап 6. Проверка связи

1. На телефоне открой `https://IP_НОУТБУКА:8000`.
2. Напиши текстом «кто ты» → должен прийти ответ и он появится на экране Клешни.
3. В Serial Monitor ESP32 должно появиться:

```text
Ноутбук найден: 192.168.1.72
Ноутбук на связи
```

Если «Ноутбук не найден»:

- ESP32 должен быть в одной сети с ноутбуком;
- проверить, что UDP-порт 7777 не закрыт файрволом;
- можно вписать IP вручную в `config.h`:

```cpp
constexpr char BRAIN_HOST[] = "192.168.1.10";
```

## Этап 7. Микрофон робота

На веб-пульте Клешни (`http://192.168.4.1` или адрес ESP32 в сети) есть кнопка
**«Сказать Клешне»**. Нажми её, скажи фразу, замолчи.

Что должно быть:

1. Клешня показывает «Слушаю...».
2. Запись идёт, пока не наберётся пауза тишины ~0,7 с (максимум 4 с).
3. На экране — «Отправляю вопрос...», потом «Думаю...».
4. В Serial Monitor:

```text
Клешня услышала: привет клешня
Клешня: Привет! Я Клешня...
```

Если «Я не расслышала»:

- подними чувствительность: в `config.h` уменьши `MIC_NOISE_GATE` (например, 260 → 150);
- проверь, что `OUT` микрофона really на GPIO34, а не на AOUT.

## Этап 8. Подключение моторов

Драйвер: двухканальный H-мост. Распиновка разъёма (как на фото):

```text
NC AIN2 AIN1 STBY BIN1 BIN2 | NC GND VM | NC GND | AO1 AO2 BO2 BO1 GND
```

Подключение:

```text
GPIO23 → AIN1     мотор А (левая сторона ног)
GPIO32 → AIN2
GPIO14 → BIN1     мотор Б (правая сторона ног)
GPIO16 → BIN2
GPIO18 → STBY

AO1 → мотор А: «+»      AO2 → мотор А: «−»
BO1 → мотор Б: «+»      BO2 → мотор Б: «−»

VM  → плюс аккумулятора моторов (6–12 В)
GND → минус аккумулятора
GND → общий GND ESP32        ← обязательно
```

Если на плате драйвера есть выводы `PWMA`/`PWMB` — их тоже можно
использовать, но по умолчанию скорость идёт на `AIN1`/`BIN1`
(`PIN_PWMA = -1` в `config.h`).

### Включение ходьбы

В `config.h` поменяй:

```cpp
constexpr bool MOVEMENT_ENABLED = true;
```

Перепрошей.

### Проверка

1. Подними робота со стола.
2. Добавь кнопки движения в пульт (см. ниже) или используй Serial-команды.
3. Если «Вперёд» уезжает назад — в `config.h` поменяй `MOTOR_B_REVERSED`
   на `false`, либо переставь провода мотора Б на `BO1`/`BO2`.
4. Если моторы молчат: проверь `STBY` (должен быть HIGH), общую землю
   и питание на `VM`.

### Питание

9 В «Крона» даёт примерно 0,5 А — большой мотор с редуктором под
нагрузкой столько не возьмёт. Нужен источник помощнее. Сам H-мост
«съедает» 2–3 В на нагрев: с 12 В на моторы придёт примерно 9–10 В.

## Этап 9. Настройка клешней

Домашняя поза и границы углов — в `config.h`:

```cpp
constexpr int HOME_LARM  = 10;   // 0 = вниз, 150 = вверх
constexpr int HOME_RARM  = 10;
constexpr int HOME_LCLAW = 20;   // 20 = сжата, 90 = раскрыта
constexpr int HOME_RCLAW = 20;
```

Правые приводы инвертированы программой — симметрия сохраняется.

Если привод упирается в механику и греется — немедленно сними питание и
переставь качалку.

## Этап 10. Частые проблемы

### Клешня зависла в «думаю»

Больше не зависает: сработает таймер 12 секунд. Если это происходит —
посмотри в Serial Monitor, дошёл ли ответ от ноутбука.

### Зуммер пищит постоянно

Значит это **активный** зуммер, а не пассивный. Тогда в `config.h`:

```cpp
constexpr bool BUZZER_IS_ACTIVE = true;
```

и в `beep()` в `CrabRobot.ino` замени тело на:

```cpp
digitalWrite(PIN_BUZZER, HIGH);
delay(durationMs);
digitalWrite(PIN_BUZZER, LOW);
```

(в файле это помечено комментарием «Важно» — найди и поправь).

Если пищит только при смене эмоции — поставь `EMOTION_SOUND = false`
(уже стоит по умолчанию).

### Микрофон молчит

- `OUT` микрофона → GPIO34 (не AOUT).
- Проверь Serial Monitor: `Микрофон: GPIO34, 8000 Гц, до 4 с`.
- Уменьши `MIC_NOISE_GATE` в `config.h`, если комната шумная.

### Whisper не распознаёт 8 кГц

Так и должно быть: 8 кГц — это потолок для ESP32. Если распознавание
полное, но с ошибками — это нормально. Можно попробовать `--stt small`
в запуске `brain_v2.py` (точнее, но медленнее).

### Экран молчит

Проверь, что оба OLED на 3V3 (не на 5V), и SDA/SCL не перепутаны:
у глаза **SDA=GPIO4, SCL=GPIO5**, у рта **SDA=GPIO21, SCL=GPIO22**.

## Этап 11. Порядок проверки перед корпусом

- [ ] ESP32 стабильно работает от USB
- [ ] оба OLED включаются
- [ ] зуммер пищит коротким чирпом, а не гудит
- [ ] пульт открывается
- [ ] «Сказать Клешне» → речь распознаётся, ответ на экране
- [ ] каждый сервопривод двигается отдельно и вместе
- [ ] моторы крутятся в обе стороны
- [ ] при движении сервоприводов не проседают экраны и Wi-Fi

Только после этого — корпус.
